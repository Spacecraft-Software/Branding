# Contributing to Branding

Spacecraft Software is a **personal hobby project**, and the marks in this
repository are the maintainer's own design. Please read this before opening an
issue or pull request.

## What Is Welcome

- **Reports** of a mark that renders wrongly in some tool, or of a project
  still drawing an outdated copy instead of this repository.
- **Technical fixes** that leave the design unchanged: a smaller or cleaner
  SVG, a missing `viewBox`, a stray attribute.

## What Is Not Guaranteed

- **Design changes.** The marks are set by the maintainer alone; a redesign
  proposal is welcome as an issue, but it is not a guaranteed change.
- **Response time.** Expect days to weeks, not hours.

## Licensing of Contributions

By submitting a contribution you agree that it is licensed under
**CC-BY-SA-4.0**, the same terms as this repository. Contributions that cannot
be licensed under CC-BY-SA-4.0 cannot be accepted.

## Commits

Every commit must be signed and show "Verified" on GitHub (Standard §6.3).
